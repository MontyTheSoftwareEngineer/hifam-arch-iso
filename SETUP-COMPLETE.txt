📋 Next Steps:

1️⃣  BUILD THE ISO:
    cd ~/hifam-arch
    ./build-iso.sh

    (Requires: sudo pacman -S archiso)
    Time: ~10-20 minutes
    Output: ~/hifam-arch-iso-output/

2️⃣  TEST IN VM (Optional but recommended):
    qemu-system-x86_64 -enable-kvm -m 4G -boot d \
        -cdrom ~/hifam-arch-iso-output/hifam-arch-*.iso

3️⃣  WRITE TO USB:
    sudo dd if=~/hifam-arch-iso-output/hifam-arch-*.iso \
            of=/dev/sdX bs=4M status=progress oflag=sync

4️⃣  BOOT & INSTALL:
    • Boot from USB
    • Login as root (no password)
    • Run: ./install-hifam.sh
    • Follow the prompts
